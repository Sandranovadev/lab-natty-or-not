# Criando avatar com inteligência Artificial #

## 📒 Descrição
Criação de um avatar utilizando a inteligência artificial, com animação falando um script definido por mim.

## 🤖 Tecnologias Utilizadas
Utilizei a ferramenta HeyGen

## 🧐 Processo de Criação
Abri a ferramenta HeyGen, criei uma conta como usuário free. Busquei um avatar criado pela inteligência artificial, criei um texto para interação, e cliquei em gerar para que a ferramenta gerasse o vídeo.

## 🚀 Resultados
Meu avatar tem movimento e fala o script digitado por mim.
